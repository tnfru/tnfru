### Lars Müller · AI Engineer, Düsseldorf

I build AI agents and systems that hold up in regulated environments.

#### [Monti](https://monti.med.uni-duesseldorf.de) · University Hospital Düsseldorf

An early‑warning system for cancer treatment. A wristband worn at home replaces the check‑up every few days: a model learns each patient's normal pattern and alerts the hospital when it drifts. I build the study platform and the detection, from the model to the alert threshold. Running with patients in Düsseldorf and Aachen since 2025.

Studies: [npj Digital Medicine 2023](https://doi.org/10.1038/s41746-023-00847-2) · [EHJ Digital Health 2025](https://academic.oup.com/ehjdh/advance-article/doi/10.1093/ehjdh/ztaf004/8221836)
